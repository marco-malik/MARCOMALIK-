رابطہ چیک ہو رہا ہے…

محفوظ dashboard login

Pairing code اور QR صرف authorized owner کے لیے دستیاب ہیں۔

Password server کی DASHBOARD_PASSWORD environment variable میں set ہونا چاہیے۔ اسے WhatsApp number یا API key نہ بنائیں۔

تیاری ہو رہی ہے…

QR سے connect کریں

WhatsApp → Linked devices → Link a device کھول کر QR scan کریں۔

QR code یہاں ظاہر ہوگا۔

Phone number سے connect کریں

Country code کے ساتھ number لکھیں، مگر +، spaces یا dashes نہ لگائیں۔

WhatsApp → Linked devices → Link with phone number پر یہ code درج کریں۔

مختصر setup

  1. پہلے dashboard password سے login کریں۔
  2. QR scan کریں یا phone number سے pairing code بنائیں۔
  3. WhatsApp میں code confirm ہونے تک browser بند نہ کریں۔
  4. Connected آنے کے بعد bot online ہے؛ session server پر محفوظ ہو جائے گی۔

QR، pairing code اور session کسی کے ساتھ share نہ کریں۔ یہ dashboard صرف HTTPS deployment پر چلائیں۔
